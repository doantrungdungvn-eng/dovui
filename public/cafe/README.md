# Café 247 — giao diện quán cà phê

- Nền sân vườn sạch, không còn khách/người hoặc nhãn tên được vẽ sẵn trong hình nền.
- Nhân vật mới là khách ngồi trên ghế, cầm tách cà phê; không dùng sprite ngồi tụng kinh.
- Tối đa 5 nhân vật cùng lúc (4 khách demo + 1 người chơi).
- Bố trí chỗ ngồi theo các bàn trong nền mới, giảm chồng lấn.
- Giữ nguyên gọi món, âm thanh, bảng khách quen và trò chuyện.

Giữ nguyên thư mục `assets` và file `index.html` khi cập nhật.
